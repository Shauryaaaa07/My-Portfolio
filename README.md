# ⚡ Shaurya Pratap Singh — Personal Developer Portfolio

An ultra-premium, responsive, high-performance developer portfolio built with modern vanilla web standards (HTML5, CSS3, JavaScript ES6+), featuring interactive neural network particle physics, 3D card tilt micro-interactions, dynamic typewriter effects, and a sophisticated Developer Slate & Emerald aesthetic.

🌐 **Live URL (via GitHub Pages):** [https://shauryaaaa07.github.io/My-Portfolio/](https://shauryaaaa07.github.io/My-Portfolio/)

---

## 🌟 Key Features

- 🌌 **Interactive Neural Canvas:** Real-time particle connection mesh rendered on HTML5 canvas with 60 FPS performance and mouse attraction.
- 💡 **Dynamic Mouse Spotlight:** Subtle radial spotlight gradient tracking cursor movement.
- ⌨️ **Typewriter Text Rotation:** Seamless cyclical typewriter effect highlighting multi-disciplinary roles.
- 🗂️ **Filterable Skills Matrix:** Categorized technical stack tabs (Languages, AI & Vision, Data Analytics, Tools) with real-time DOM filtering.
- 🃏 **3D Perspective Tilt:** Interactive dynamic perspective tilt micro-interactions on the profile frame and project showcase cards.
- 📋 **1-Click Email Copy:** Instant clipboard interaction with non-intrusive toast notifications.
- 📱 **Mobile-First Responsive Design:** Fully optimized with custom drawer navigation for iOS, Android, tablets, and ultra-wide desktops.
- ⚡ **Zero Build Step & Lightning Fast:** Pure vanilla architecture that deploys instantly on GitHub Pages with zero compile time and perfect Lighthouse performance scores.

## 🛠️ Tech Stack

- **Markup:** Semantic HTML5
- **Styling:** Modern CSS3 (CSS Variables, Flexbox, CSS Grid, Glassmorphism `backdrop-filter`)

- **Typography:** Inter & JetBrains Mono (Google Fonts)
- **Icons:** FontAwesome 6 (CDN)

## 🚀 How to Enable GitHub Pages (1-Click Deployment)

1. Open this repository on GitHub: [github.com/Shauryaaaa07/My-Portfolio](https://github.com/Shauryaaaa07/My-Portfolio)
2. Click on the **Settings** tab.
3. On the left sidebar, click on **Pages**.
4. Under **Build and deployment** &rarr; **Source**, select **"Deploy from a branch"**.
5. Under **Branch**, select `main` and folder `/ (root)`, then click **Save**.
6. Within 60 seconds, your portfolio will be live at:
   👉 **https://shauryaaaa07.github.io/My-Portfolio/**
